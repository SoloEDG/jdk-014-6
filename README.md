# PANEL

安装：`npm install`

本地启动：`npm run dev`

生产构建：`npm run typecheck && npm run build`

Docker 启动：`docker compose up --build`，访问 http://localhost:3014。

## 双版本对照工作台

顶栏点击「双版本对照」进入，把原稿与重绘稿放在同一工作区并排比对。

- **并排对照**：两侧各自独立翻页、选格，页数、裁切尺寸、每页格子数都可以不同；一格可对应多格，也允许暂时无对应。
- **不按序号冒充剧情**：自动匹配只依据台词文本、说话人、声景与版面几何，重排/增删格子/重新裁切不会产生“同序号假对应”。
- **建议可预览、可批量、可撤销**：自动匹配产出的是 `suggested` 建议（含置信度、依据、歧义标记），支持单条接受/否决、批量接受无歧义项，以及撤销/重做。
- **联动只走可信关联**：仅 `confirmed` 关联可联跳；建议态、被否决或无对应分镜会停在当前版本并提示。
- **声源只来自主读版本**：可在原稿 / 重绘稿间切换主读，声景仅跟随主读侧分镜。
- **书签/进度迁移**：迁移前列出无对应、歧义、一格多目标等风险；按批次迁移并记录。回退只删除该批次迁入的书签，迁移后在新稿手工新增的书签不受影响，两份原稿始终完整保留。

对照数据保存在浏览器 localStorage（键名 `panel-compare-v1:*`），与沉浸阅读会话分开存储。
